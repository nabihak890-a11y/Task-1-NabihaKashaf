# SaaS Startup Landing

This repository contains the source code for a simple SaaS startup landing page.

- Static landing page built with `index.html`, `style.css`, `script.js`, and the `images/` folder.
- No framework required; easy to customize.

- Hero section
- Features / Benefits section
- Call-to-action button
- Responsive layout (mobile-friendly)
- Simple JavaScript interactions in `script.js`

- `index.html` — The landing page HTML
- `style.css` — Styles and layout
- `script.js` — Client-side interactions
- `images/` — Image assets
- 
1. Open locally in your browser:
   - Open `index.html` in your browser to view the page.
2. Run a simple local server (recommended):

   Using Python 3 in a terminal:

   ```bash
   cd path/to/saas-startup-landing
   python -m http.server 8000
   ```

   Then open `http://localhost:8000` in your browser.

- Edit `style.css` to change styles.
- Modify `index.html` to update content and sections.
- Add or update functions in `script.js` to enhance interactivity.


For small improvements, submit a pull request. For larger changes, please open an issue first to discuss.
